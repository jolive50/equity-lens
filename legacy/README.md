# Legacy Code Archive

## Purpose

This folder contains **legacy/outdated code** from previous development iterations. These files should **NOT** be modified or used for the current FreshStart MVP project.

## Contents

- **data/** - Old data storage, batch pipelines, and ChromaDB instances
- **docs/** - Old documentation and resources
- **frontend/** - Previous Next.js frontend (before FreshStart reorg)
- **model/** - Old model implementations and FinBERT downloads
- **pipelines/** - Previous batch/realtime pipeline architecture
- **scripts/** - Old utility scripts for data collection and training
- **tests/** - Old test files (replaced by FreshStart/tests/)
- **webscraping/** - Old web scraping configurations

These files represent earlier iterations of the capstone project before we:
1. Reorganized the codebase under FreshStart/
2. Established clear role divisions for team members
3. Simplified the architecture for MVP scope
