# AI Capstone Notes

## Data Sources Under Consideration

- **Yahoo Finance** - free via `yfinance` (historical candles, fundamentals).
- **Alpha Vantage** - free tier (500 calls/day) for prices and fundamentals.
- **Tiingo** - free plan (500 calls/day) covering end-of-day data.
- **IEX Cloud** - 50,000 messages/month on the free tier.
- **Nasdaq Data Link** - curated datasets; some series remain free.
- **News APIs** - NewsAPI, Finnhub, Reddit/Twitter wrappers for sentiment feeds.

## Core Personas & Goals

### Anonymous User
- Look up a ticker and view a conservative next-day outlook.
- Read a short summary of market sentiment.

### Registered User
- Persist a watchlist.
- Review recent analysis history.
- Compare multiple tickers side by side.

### Premium User
- Evaluate an entire watchlist/portfolio at once.
- Receive alerts when predictions change materially.
- View plain-language explanations and model confidence history.
- Track institutional, insider, and congressional trading activity.

### Administrator
- Monitor usage metrics (popular tickers, active users).
- Update AI models and data adapters without redeploying the stack.
- Manage user accounts and subscription tiers.
- Observe system performance and troubleshooting logs.

## Detailed Use Case: Stock Prediction with Sentiment Context

**Preconditions**
- LangGraph workflow is configured with trained models (forecaster, FinBERT).
- External data adapters have valid API keys and are reachable.
- User is on the web app (premium features require authentication).

**Main Flow**
1. **User input**  
   Basic user enters a ticker (for example `AAPL`); premium user may select an entire watchlist.
2. **Data collection**  
   The backend fetches recent prices, fundamentals, and sentiment signals.
3. **Prediction**  
   The probabilistic forecaster produces a directional call with confidence.  
   - If confidence >= 0.95 -> surface directional recommendation.  
   - Otherwise annotate as "trend insight only" with a caution flag.
4. **Sentiment analysis**  
   FinBERT scores relevant headlines and social content.  
   - Basic users see a short verdict (positive/neutral/negative).  
   - Premium users receive narrative context and key drivers.
5. **Result delivery**  
   - Basic: next-day prediction, quick sentiment snapshot.  
   - Premium: watchlist summary, alerts (if enabled), explanation narrative, accuracy history, smart-money signals.

**Postconditions**
- Users receive actionable insight aligned with their tier.
- Explanations emphasise that forecasts are informational, not investment advice.
- Admin dashboards record usage for monitoring.
